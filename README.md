# SOC-Automation-Scripts

This repository contains small, practical automation scripts I've written or studied as part of my work as a Tier I SOC Analyst. These scripts support alert triage, log parsing, enrichment, and basic Zero Trust visibility.

## Why This Repo Exists
I'm transitioning from SOC operations into Zero Trust engineering. Automation is a key skill in both areas, so these scripts help me learn Python while building practical tools for investigation workflows.

## Scripts Included
- **log_parser_basic.py** — Parses simple Windows/Linux log lines and extracts key fields.
- **zscaler_log_parser.py** — Basic parsing of Zscaler ZIA/ZPA logs (anonymized examples).
- **url_enrichment_virustotal.py** — Demonstrates URL enrichment using a mock VirusTotal workflow.

## What I'm Learning
- Python fundamentals
- Automating repetitive SOC tasks
- Understanding Zscaler log structure
- How automation supports Zero Trust visibility
