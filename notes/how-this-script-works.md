# How This Script Works

This script is part of my SOC automation learning. I'm using small Python examples to understand how logs are structured and how automation can support alert triage.

## What This Script Demonstrates
- How to read a file line-by-line
- How to split log fields
- How to extract timestamps, log levels, and messages
- How to structure parsed data into a dictionary
- How automation can reduce repetitive triage tasks

## Why This Matters
Understanding how logs are parsed is foundational for:
- Detection engineering
- SIEM parsing
- Zscaler log analysis
- Zero Trust visibility
- Building future automation workflows
